# reference-app frontend (React SPA)

Vite + React 19 + React Router single-page app for reference-app. Built on the
`@zero-design-system/react` component library (ADR 007), aliased directly to the
monorepo source at `packages/react-ui/src`.

## Routes

| Route | Screen | Key testids |
|-------|--------|-------------|
| `/` | `HomePage` | `reference-layout`, `health-panel`/`health-status`, `items-list`/`item-row`, `welcome-panel`/`welcome-message`, `logout-button` |
| `/login` | `LoginPage` | `login-panel`, `login-form`, `login-input`, `password-input`, `submit-button`, `error-message`, `register-link`, `login-form-title` |
| `/register` | `RegisterPage` | `register-panel`, `register-form`, `confirm-password-input`, `submit-button`, `login-link`, `register-form-title` |

## Contracts preserved for Selenide

- Every `data-testid` used by `tests/src/test/java/pages/*.java`.
- Exact strings: validation messages (`lib/messages.ts`), `Welcome, {username}!`,
  `→ {status} | service: {service}`, form titles `Login Form` / `Register`.

## Header

The design-system header is SSOT and is **not** reimplemented in React. `index.html`
sets `window.headerConfig` and `main.tsx` injects `/js/header.js` at runtime.

## Scripts

```bash
npm run dev        # Vite dev server
npm run build      # -> ../backend/src/main/resources/static (index.html + assets/)
npm run typecheck  # tsc --noEmit
npm test           # Vitest + React Testing Library (= pyramid frontend_rtl)
```

## Build notes

- `outDir` is the backend static dir with `emptyOutDir: false` so the design-system
  embed (`css/`, `js/`, `templates/`) and `preview/` catalog are preserved.
- Asset filenames are stable (unhashed) to keep the committed static output diff-clean.
- Peer CSS (design-system primitives + app styles) is bundled from the committed
  `../backend/.../static/css` so the build is self-contained and visual baselines hold.

## PWA baseline

Generated by [`vite-plugin-pwa`](https://vite-pwa-org.netlify.app/) (Workbox `generateSW`)
into the backend static dir on `npm run build`:

| Output | Role |
|--------|------|
| `manifest.webmanifest` | Web app manifest — `standalone`, `theme_color: #2c2a26`, `scope`/`start_url: /`, 192/512 icons |
| `sw.js` (+ `workbox-*.js`) | Service worker — precache app shell/assets, nav fallback → `index.html`, `/api/*` denylisted (online-only) |
| `public/icons/icon-{192,512}.png` | Install icons (copied verbatim) |

Precache is scoped to the SPA shell only (`index.html`, `assets/`, `manifest.webmanifest`,
icons) because `outDir` is the shared backend static dir. No offline API/JWT caching, no
push, no background sync. SW registered in `src/pwa/registerServiceWorker.ts` (called from
`src/main.tsx`).
